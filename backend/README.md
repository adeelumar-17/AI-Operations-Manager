# AI Operations Manager

This project provides a starter structure for an AI-powered operations workflow with agent tools, RAG services, integrations, and tests.

## Structure

- `app/agents` contains orchestration and tool modules.
- `app/rag` contains retrieval and embedding utilities.
- `app/integrations` contains external integration modules.
- `data/` holds seed data and policy files.
- `docker/` is reserved for container configuration.
